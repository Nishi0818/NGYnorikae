# Noto Sans JP の利用記録

このアプリは、日本語UIの表示に **Noto Sans JP** を使用しています。フォントファイルは、Google Fontsの公式リポジトリで配布されている可変フォント `NotoSansJP[wght].ttf` から、アプリで使う文字を残して作成したサブセットを同梱しています。

| 項目 | 内容 |
| --- | --- |
| フォント | Noto Sans JP |
| ライセンス | SIL Open Font License 1.1（OFL-1.1） |
| 配布元 | [Google Fonts の Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP) |
| ソース | [google/fonts: ofl/notosansjp](https://github.com/google/fonts/tree/main/ofl/notosansjp) |
| 同梱ライセンス原文 | `licenses/OFL-NotoSansJP.txt` |
| 同梱フォント | `assets/fonts/NotoSansJP-Subset.ttf`（アプリ内使用文字のサブセット） |

Notoの公式案内では、OFLのもとでデジタル・商用を含む製品やプロジェクトへの利用が認められています。ただし、フォントそのものを単体で販売することはできません。詳細は同梱したOFL原文を参照してください。[1][2]

[1]: https://notofonts.github.io/noto-docs/website/use/
[2]: https://github.com/google/fonts/blob/main/ofl/notosansjp/OFL.txt
